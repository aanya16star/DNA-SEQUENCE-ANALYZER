# Project Statement

## 1. Project Title
DNA Sequence Analyzer

## 2. Problem Statement
DNA sequences contain biological information and genetic data which are represented using four main bases: A, T, G and C. Performing these operations manually is a time consuming process and can lead to errors. The purpose of this project is to create a simple Python command-line program that performs basic DNA sequence analysis within seconds without requiring much human effort.

## 3. Scope of the Project
The main target of this project is to analyse the DNA sequences using a python program. It includes DNA validation, nucleotide counting, GC content, complementary and reverse-complement generation, DNA-to-mRNA transcription, mRNA-to-protein translation, and DNA pattern searching. It is intended for basic educational and introductory bioinformatics purposes.

## 4. Target Users
- Students learning Python
- Biotechnology students
- Bioengineering students
- Bioinformatics students
- Beginners learning computational biology
- Users who want to understand basic DNA sequence operations

## 5. High-Level Features
### 5.1 DNA Input and Validation
Checks whether the sequence contains only the bases A, T, G and C.

### 5.2 Nucleotide Analysis
Counts A, T, G and C and calculates GC content.

### 5.3 DNA Strand Analysis
Generates the complementary strand and reverse complement.

### 5.4 Genetic Information Processing
Converts DNA into mRNA and translates mRNA into amino acids using a codon table.

### 5.5 Pattern Searching
Searches for a DNA pattern and displays its positions.

## 6. Main Input
DNA sequence, for example `ATGCAC`, and optionally a DNA pattern for searching.

## 7. Main Output
DNA length, nucleotide counts, GC content, complementary strand, reverse complement, mRNA, protein sequence, and pattern positions.

## 8. User Interaction

Start -> Display Menu -> Enter DNA -> Validate -> Select Operation -> Process -> Display Result -> Return to Menu -> Exit

## 9. Technologies Used
Python 3, command-line interface, functions, strings, lists, dictionaries, loops, conditional statements, Git and GitHub.

## 10. Expected Outcome
A working command-line application that performs basic DNA sequence analysis and demonstrates Python programming concepts applied to bioinformatics.
